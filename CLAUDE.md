# Solidstate7.github.io

Eunjae Lee's portfolio site, served by GitHub Pages.

## Push to deploy

A push to `main` publishes https://solidstate7.github.io/ (GitHub Pages, legacy build from `main`, path `/`). There is no staging and no review step between the push and the live site, so a push here is a publish: confirm the content with the operator first, as the global publishing rule says.
