Organism

Open-source Claude Code plugin, v0.1.2

Since Jun 2026

It records why agent-written code changed, and links each decision to the commits that carry it out.

  • Saves every AI coding session as a markdown note, with secrets redacted before anything is written.
  • Writes decision records, links them both ways to the commits that carry them out through git notes, and leaves a brief for the next session.
  • Its publish guard reads what a push or deploy actually sends, from unpushed commits to a deploy’s folder, and blocks it when a private term is inside.
  • Written in Python (standard library only), bash and Node, and wired into Claude Code through hooks, skills and a plugin manifest.

How I build

When an agent writes the code, the reason behind each change is the first thing to go. I built Organism to keep it.

  1. Session

    Organism saves each Claude Code session as a markdown note and redacts secrets first.

  2. /handoff

    At the end, it writes a decision record for what was decided, and a brief that opens the next session.

  3. Record and commit

    Each record links to the commits that carry it out, and each commit back to its record, in git notes.

Purrfluent is built this way, with 109 decision records and 218 commits that link back to the decision behind them. I make the longer argument in the essay Semantic Sovereignty.
